Scheduled Auto Clicker - Windows 10/11 (64-bit)

ফিচার:
- Pick Position বাটনে ক্লিক করলে ৫ সেকেন্ড সময় দেয়।
- এই সময়ে মাউসকে যে জায়গায় ক্লিক করাতে চান সেখানে রাখুন।
- তারিখ ও সময় সেট করে Schedule Click চাপুন।
- নির্ধারিত সময়ে ওই স্ক্রিন কো-অর্ডিনেটে একবার বাম ক্লিক হবে।
- Cancel দিয়ে নির্ধারিত ক্লিক বাতিল করা যায়।

EXE বানানোর নিয়ম:
1. Windows 10/11 64-bit কম্পিউটারে .NET 8 SDK ইনস্টল করুন:
   https://dotnet.microsoft.com/download/dotnet/8.0
2. এই ZIP Extract করুন।
3. Build_EXE.bat-এ ডাবল-ক্লিক করুন।
4. Build সফল হলে EXE পাবেন:
   bin\Release\net8.0-windows\win-x64\publish\ScheduledAutoClicker.exe

গুরুত্বপূর্ণ:
- এটি স্ক্রিনের নির্দিষ্ট X/Y অবস্থানে ক্লিক করে; ওয়েবসাইটের HTML/CSS selector ব্যবহার করে না।
- নির্ধারিত সময়ে Windows চালু থাকতে হবে এবং কম্পিউটার Sleep অবস্থায় থাকা যাবে না।
- ক্লিকের জায়গা সঠিক কি না আগে Notepad বা নিজের পরীক্ষামূলক পেজে পরীক্ষা করুন।
- সফটওয়্যারটি চালু থাকা অবস্থায় মাউসের অবস্থান নির্ধারণের সময় সতর্ক থাকুন।
- শুধু নিজের বা অনুমতিপ্রাপ্ত অ্যাপ/ওয়েবসাইটে ব্যবহার করুন।
